# CALL4 訴訟資料 引用論文リスト

**公開ページ**: https://shio-koji.github.io/call4-citation-list/

CALL4（[call4.jp](https://www.call4.jp/)）に公開されている公共訴訟96件について、
**その訴訟資料が引用している学術文献**を抽出してリスト化したもの。

## いまどこまで進んだか

**全件展開まで完了。** 公開96ケース全部の引用文献リストができ、公開ページに載せてある。

- [中間報告01_訴訟資料の取得可否.md](中間報告01_訴訟資料の取得可否.md) — 何件の資料があり、何件がテキスト化済みか
- [中間報告02_APIで何が取れるか.md](中間報告02_APIで何が取れるか.md) — API仕様の実測（文字数上限・PDF・has_textフラグ）
- [中間報告03_引用文献リストの試作.md](中間報告03_引用文献リストの試作.md) — 4ケースでの試作（経緯の記録）
- [中間報告04_全96ケースの引用文献リスト.md](中間報告04_全96ケースの引用文献リスト.md) — 全96ケースの結果
- [中間報告05_複数ケースで引用されている文献.md](中間報告05_複数ケースで引用されている文献.md) — **複数ケースで引用された170件の精査**（名寄せの修正を含む）

**次にやること** — 省略引用（`前掲注(24)`）の解決、判例の抽出、証拠として提出された論文の抽出、
書誌の名寄せ（版違いのまとめ）。

## 分かっていること（要点）

| | |
|---|---|
| 公開ケース | 96件 |
| 訴訟資料 | 7,090件（書面4,819 / 証拠1,956 / 判決315） |
| 本文の取得 | 7,090件すべて取得済み。所要2.26時間（同時3本）。うち本文があるのは6,888件 |
| 引用抽出 | 学術文献 **1,880件**（書籍1,029 / 論文762 / 英語89） |
| 横断引用 | 170件の文献が複数の訴訟で引用されている。最多は長谷部恭男編『註釈日本国憲法(2)』と佐藤幸治『日本国憲法論』の各8ケース |
| うち分野を越えるもの | 44件。主題タグが重ならない訴訟にまたがる。ほぼ全部が憲法の体系書・注釈書 |
| 名寄せ | タイトルだけでまとめると同名異書（『親族法』は6人が別々に執筆）が混ざるため、タイトル＋著者で1著作としている |
| APIドキュメントの50,000文字上限 | **実際には掛かっていない**（実測最長 373,189文字） |
| PDFそのもの | APIでは取れないが、サイトのHTMLから全件取れる（資料IDとの対応づけ99.8%） |
| PDFの中身 | 多くが画像スキャン。**APIのテキストはCALL4側でOCR済み**で、自前処理より質が高い |
| `has_text` フラグ | `True`は100%信用できる。`False`でも22%は本文が取れる |
| 取れない資料 | 手元でOCRすれば救えるものがある（実証済み）。ただし0バイトのファイルと動画(.mp4)は救えない |

## データの置き場所

`cache/` は**バージョン管理していない**（PDFだけで320MBあり、スクリプトで再生成できるため）。

| | |
|---|---|
| `cache/cases_list.json` | 全ケース一覧 |
| `cache/docs_<ケースID>.json` | 資料一覧のAPI応答 |
| `cache/text/<資料ID>.json` | 本文のAPI応答（7,090件） |
| `cache/pdf_urls.json` | 資料IDとPDFのURLの対応表 |
| `cache/matpage/<ケースID>.html` | 資料一覧ページのHTML（PDFリンクの取得元） |
| `cache/pdf/<資料ID>.pdf` | ダウンロードしたPDF |

## APIの叩き方

`POST https://www.call4.jp/flight_api/mcp/sse` に JSON-RPC 2.0。認証不要。
`Accept: application/json` を付けると素のJSONで返る。

**落とし穴** — 応答は二重にJSONになっている（`result.content[0].text` を再度パースする）。
失敗はHTTP 500で返る。さらに `content[0].text` が文字列でなく `false` で返る資料があるので型チェックが要る。

**取得は連続で叩かない。** 1件あたり中央値5.2秒かかる（サーバー側で本文抽出をしているため）。
同時3本までに抑えること。

## 公開ページ

`docs/` を GitHub Pages（mainブランチの `/docs`）で配信している。
件数が2,497件あるので、データは `docs/data.json` に外出しし、一覧は100件ずつ描画している。
更新は `python3 11_build_site.py` で作り直してコミットするだけ。

## 扱いの注意

公開データだが、**ケース本文・資料の権利はCALL4と各ケースの関係者にある**。
公開ページには訴訟資料からの短い抜粋（引用箇所の前後）を載せているため、
**CALL4に一度見てもらい、必要なら表示を調整する前提**で扱う。

ページ冒頭には「自動抽出であること」「人手の確認を経ていないこと」
「省略引用を拾えていないこと」を明記してある。数字が独り歩きしないようにするため。
